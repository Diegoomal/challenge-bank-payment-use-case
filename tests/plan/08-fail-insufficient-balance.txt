Scenario 08 - failure by insufficient balance

Goal:
Validate the complete failure saga when the customer account does not have
enough balance. This scenario should publish `debit.failed`, reverse the
payment, and notify the customer about the reversal.

Preparation:

docker compose up -d --build

curl -X POST http://localhost:8080/api/v1/accounts -H "Content-Type: application/json" -d '{"customer_id":"scenario-08-customer","account_holder":"Scenario 08 Customer","initial_deposit":"10.00"}'

docker compose exec -T debit_account_service python -c "from decimal import Decimal; from adapters.persistence.sqlite_account_repository import SQLiteAccountRepository; from domain.account import Account; r=SQLiteAccountRepository('/data/debit_account.db'); a=r.get_by_customer_id('scenario-08-customer') or Account.create(customer_id='scenario-08-customer', holder_name='Scenario 08 Customer', balance=Decimal('10.00')); r.save(a); print(a.id, a.customer_id, a.balance)"

docker compose exec -T credit_account_service python -c "from decimal import Decimal; from adapters.persistence.sqlite_account_repository import SQLiteAccountRepository; from domain.account import Account; r=SQLiteAccountRepository('/data/credit_account.db'); a=r.get_by_customer_id('scenario-08-merchant') or Account.create(customer_id='scenario-08-merchant', holder_name='Scenario 08 Merchant', balance=Decimal('0.00')); r.save(a); print(a.id, a.customer_id, a.balance)"

Action:

curl -X POST http://localhost:8080/api/v1/payments/start -H "Content-Type: application/json" -d '{"customer_id":"scenario-08-customer","merchant_id":"scenario-08-merchant","amount":"50.00","payment_method":"ACCOUNT_BALANCE"}'

Wait a few seconds, then inspect the result:

docker compose exec -T start_payment_service python -c "import sqlite3; c=sqlite3.connect('/data/start_payment.db'); print(c.execute('select id, customer_id, merchant_id, amount, status from transactions where customer_id=? order by created_at desc limit 5', ('scenario-08-customer',)).fetchall())"
docker compose exec -T debit_account_service python -c "import sqlite3; c=sqlite3.connect('/data/debit_account.db'); print('accounts=', c.execute('select customer_id, balance from accounts where customer_id=?', ('scenario-08-customer',)).fetchall()); print('entries=', c.execute('select transaction_id, amount, entry_type from accounting_entries order by created_at desc limit 5').fetchall()); print('outbox=', c.execute('select event_name, routing_key, status, payload from outbox_events order by created_at desc limit 5').fetchall())"
docker compose exec -T credit_account_service python -c "import sqlite3; c=sqlite3.connect('/data/credit_account.db'); print('accounts=', c.execute('select customer_id, balance from accounts where customer_id=?', ('scenario-08-merchant',)).fetchall()); print('entries=', c.execute('select transaction_id, amount, entry_type from accounting_entries order by created_at desc limit 5').fetchall()); print('outbox=', c.execute('select event_name, routing_key, status from outbox_events order by created_at desc limit 5').fetchall())"
docker compose exec -T reverse_payment_service python -c "import sqlite3; c=sqlite3.connect('/data/reverse_payment.db'); print('transactions=', c.execute('select id, status, reversal_reason from transactions where customer_id=? order by updated_at desc limit 5', ('scenario-08-customer',)).fetchall()); print('outbox=', c.execute('select event_name, routing_key, status, payload from outbox_events order by created_at desc limit 5').fetchall())"
docker compose exec -T confirm_payment_service python -c "import sqlite3; c=sqlite3.connect('/data/confirm_payment.db'); print(c.execute('select id, customer_id, merchant_id, status, confirmed_at from transactions where customer_id=? order by updated_at desc limit 5', ('scenario-08-customer',)).fetchall())"
docker compose exec -T notify_customer_service python -c "import sqlite3; c=sqlite3.connect('/data/notify_customer.db'); print(c.execute('select transaction_id, customer_id, notification_type, status from notifications where customer_id=? order by notified_at desc limit 5', ('scenario-08-customer',)).fetchall()); print('outbox=', c.execute('select event_name, routing_key, status, payload from outbox_events order by created_at desc limit 5').fetchall())"
docker compose exec -T notify_merchant_service python -c "import sqlite3; c=sqlite3.connect('/data/notify_merchant.db'); print(c.execute('select transaction_id, merchant_id, status from notifications where merchant_id=? order by notified_at desc limit 5', ('scenario-08-merchant',)).fetchall())"
docker compose exec -T issue_receipt_service python -c "import sqlite3; c=sqlite3.connect('/data/issue_receipt.db'); print(c.execute('select transaction_id, customer_id, merchant_id, status from receipts where customer_id=? order by issued_at desc limit 5', ('scenario-08-customer',)).fetchall())"

Expected behavior:

- start_payment_service starts the transaction.
- debit_account_service keeps the balance at 10.00 and publishes debit.failed with INSUFFICIENT_BALANCE.
- credit_account_service does not credit the merchant account.
- reverse_payment_service marks the transaction as REVERSED and publishes payment.reversed.
- notify_customer_service delivers a PAYMENT_REVERSED customer notification.
- confirm_payment_service does not confirm the transaction.
- notify_merchant_service does not deliver a success notification.
- issue_receipt_service does not issue a receipt.
