Scenario 05 - failure in credit account service

Goal:
Validate behavior when customer debit succeeds but the merchant account cannot
be credited. The payment should be reversed and post-confirmation services must
not run.

Preparation:

docker compose up -d --build

curl -X POST http://localhost:8080/api/v1/accounts -H "Content-Type: application/json" -d '{"customer_id":"scenario-05-customer","account_holder":"Scenario 05 Customer","initial_deposit":"100.00"}'

docker compose exec -T debit_account_service python -c "from decimal import Decimal; from adapters.persistence.sqlite_account_repository import SQLiteAccountRepository; from domain.account import Account; r=SQLiteAccountRepository('/data/debit_account.db'); a=r.get_by_customer_id('scenario-05-customer') or Account.create(customer_id='scenario-05-customer', holder_name='Scenario 05 Customer', balance=Decimal('100.00')); r.save(a); print(a.id, a.customer_id, a.balance)"

Do not seed `scenario-05-merchant` in `credit_account_service`.

Action:

curl -X POST http://localhost:8080/api/v1/payments/start -H "Content-Type: application/json" -d '{"customer_id":"scenario-05-customer","merchant_id":"scenario-05-merchant","amount":"50.00","payment_method":"ACCOUNT_BALANCE"}'

Wait a few seconds, then inspect the result:

docker compose exec -T debit_account_service python -c "import sqlite3; c=sqlite3.connect('/data/debit_account.db'); print('accounts=', c.execute('select customer_id, balance from accounts where customer_id=?', ('scenario-05-customer',)).fetchall()); print('outbox=', c.execute('select event_name, routing_key, status from outbox_events order by created_at desc limit 5').fetchall())"
docker compose exec -T credit_account_service python -c "import sqlite3; c=sqlite3.connect('/data/credit_account.db'); print('merchant=', c.execute('select customer_id, balance from accounts where customer_id=?', ('scenario-05-merchant',)).fetchall()); print('outbox=', c.execute('select event_name, routing_key, status, payload from outbox_events order by created_at desc limit 5').fetchall())"
docker compose exec -T confirm_payment_service python -c "import sqlite3; c=sqlite3.connect('/data/confirm_payment.db'); print(c.execute('select id, customer_id, merchant_id, status, confirmed_at from transactions where customer_id=? order by updated_at desc limit 5', ('scenario-05-customer',)).fetchall())"
docker compose exec -T reverse_payment_service python -c "import sqlite3; c=sqlite3.connect('/data/reverse_payment.db'); print(c.execute('select id, customer_id, status, reversal_reason from transactions where customer_id=? order by updated_at desc limit 5', ('scenario-05-customer',)).fetchall())"
docker compose exec -T notify_merchant_service python -c "import sqlite3; c=sqlite3.connect('/data/notify_merchant.db'); print(c.execute('select transaction_id, merchant_id, status from notifications where merchant_id=? order by notified_at desc limit 5', ('scenario-05-merchant',)).fetchall())"
docker compose exec -T notify_customer_service python -c "import sqlite3; c=sqlite3.connect('/data/notify_customer.db'); print(c.execute('select transaction_id, customer_id, notification_type, status from notifications where customer_id=? order by notified_at desc limit 5', ('scenario-05-customer',)).fetchall())"
docker compose exec -T issue_receipt_service python -c "import sqlite3; c=sqlite3.connect('/data/issue_receipt.db'); print(c.execute('select transaction_id, customer_id, merchant_id, status from receipts where customer_id=? order by issued_at desc limit 5', ('scenario-05-customer',)).fetchall())"

Expected behavior:

- Debit succeeds and debit.completed is published.
- credit_account_service publishes credit.failed with MERCHANT_ACCOUNT_NOT_FOUND.
- reverse_payment_service marks the transaction as REVERSED.
- confirm_payment_service does not confirm the transaction.
- notify_customer_service delivers a PAYMENT_REVERSED customer notification.
- Merchant success notification and receipt are absent.
