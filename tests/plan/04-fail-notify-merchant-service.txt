Scenario 04 - failure in antepenultimate step: notify merchant

Goal:
Validate that customer notification and receipt issuing can succeed while the
merchant notification consumer is down. The payment must stay confirmed.

Preparation:

docker compose up -d --build
docker compose stop notify_merchant_consumer

curl -X POST http://localhost:8080/api/v1/accounts -H "Content-Type: application/json" -d '{"customer_id":"scenario-04-customer","account_holder":"Scenario 04 Customer","initial_deposit":"100.00"}'

docker compose exec -T debit_account_service python -c "from decimal import Decimal; from adapters.persistence.sqlite_account_repository import SQLiteAccountRepository; from domain.account import Account; r=SQLiteAccountRepository('/data/debit_account.db'); a=r.get_by_customer_id('scenario-04-customer') or Account.create(customer_id='scenario-04-customer', holder_name='Scenario 04 Customer', balance=Decimal('100.00')); r.save(a); print(a.id, a.customer_id, a.balance)"

docker compose exec -T credit_account_service python -c "from decimal import Decimal; from adapters.persistence.sqlite_account_repository import SQLiteAccountRepository; from domain.account import Account; r=SQLiteAccountRepository('/data/credit_account.db'); a=r.get_by_customer_id('scenario-04-merchant') or Account.create(customer_id='scenario-04-merchant', holder_name='Scenario 04 Merchant', balance=Decimal('0.00')); r.save(a); print(a.id, a.customer_id, a.balance)"

Action:

curl -X POST http://localhost:8080/api/v1/payments/start -H "Content-Type: application/json" -d '{"customer_id":"scenario-04-customer","merchant_id":"scenario-04-merchant","amount":"50.00","payment_method":"ACCOUNT_BALANCE"}'

Wait a few seconds, then inspect the result:

docker compose exec -T confirm_payment_service python -c "import sqlite3; c=sqlite3.connect('/data/confirm_payment.db'); print(c.execute('select id, customer_id, merchant_id, status, confirmed_at from transactions where customer_id=? order by updated_at desc limit 5', ('scenario-04-customer',)).fetchall())"
docker compose exec -T notify_merchant_service python -c "import sqlite3; c=sqlite3.connect('/data/notify_merchant.db'); print(c.execute('select transaction_id, merchant_id, status from notifications where merchant_id=? order by notified_at desc limit 5', ('scenario-04-merchant',)).fetchall())"
docker compose exec -T notify_customer_service python -c "import sqlite3; c=sqlite3.connect('/data/notify_customer.db'); print(c.execute('select transaction_id, customer_id, status from notifications where customer_id=? order by notified_at desc limit 5', ('scenario-04-customer',)).fetchall())"
docker compose exec -T issue_receipt_service python -c "import sqlite3; c=sqlite3.connect('/data/issue_receipt.db'); print(c.execute('select transaction_id, customer_id, merchant_id, status from receipts where customer_id=? order by issued_at desc limit 5', ('scenario-04-customer',)).fetchall())"

Recovery check:

docker compose start notify_merchant_consumer
docker compose logs --no-color --tail=120 notify_merchant_consumer
docker compose exec -T notify_merchant_service python -c "import sqlite3; c=sqlite3.connect('/data/notify_merchant.db'); print(c.execute('select transaction_id, merchant_id, status from notifications where merchant_id=? order by notified_at desc limit 5', ('scenario-04-merchant',)).fetchall())"

Expected behavior:

- Payment reaches CONFIRMED.
- Customer notification is delivered.
- Receipt is issued.
- Merchant notification is absent while notify_merchant_consumer is stopped.
- After notify_merchant_consumer starts again, the merchant notification becomes DELIVERED.
