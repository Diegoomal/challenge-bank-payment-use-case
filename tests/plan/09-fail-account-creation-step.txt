Scenario 09 - failure in account creation step

Goal:
Validate request validation before account creation. No account event should be
published when the account request is invalid.

Preparation:

docker compose up -d --build

Action:

curl -i -X POST http://localhost:8080/api/v1/accounts -H "Content-Type: application/json" -d '{"customer_id":"scenario-09-customer","account_holder":"Scenario 08 Customer","initial_deposit":"-10.00"}'

Inspect the result:

docker compose exec -T account_service python -c "import sqlite3; c=sqlite3.connect('/data/account.db'); print(c.execute('select id, customer_id, status from accounts where customer_id=? order by created_at desc limit 5', ('scenario-09-customer',)).fetchall()); print(c.execute('select event_name, routing_key, status from outbox_events order by created_at desc limit 5').fetchall())"
docker compose exec -T debit_account_service python -c "import sqlite3; c=sqlite3.connect('/data/debit_account.db'); print(c.execute('select customer_id, balance from accounts where customer_id=?', ('scenario-09-customer',)).fetchall())"

Expected behavior:

- HTTP response is an error.
- No account exists for scenario-09-customer in account_service.
- No account.created event is created for this request.
- No debit-service account projection exists.
